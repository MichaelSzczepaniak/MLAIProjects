## ExplainableML

This notebook covers the topic of explainability in machine learning models. As a general rule, the more powerful a model gets, the less inherently exaplainable it typically is. This notebook describes and provides examples of model-specific vs model-agnostic techniques such as:

+ coefficient importance
+ permutation importance
+ SHAP explainers
+ LIME explainers
